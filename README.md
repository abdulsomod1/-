# المكتبة الرقمية للبحوث

واجهة أمامية عربية RTL لمعهد أصول اللغة العربية الإسلامي، مبنية بـ HTML وCSS وVanilla JavaScript فقط.

## التشغيل

افتح `index.html` مباشرة، أو شغّل خادمًا محليًا من مجلد المشروع:

```bash
python -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## استبدال البيانات

- البيانات المركزية: `js/data.js`
- الشعار الرسمي: ضع الصورة المرفقة باسم `assets/logo.jpeg` دون تغيير أبعاده أو نسبه. الواجهة تستخدم هذا المسار في كل الصفحات.
- أغلفة البحوث: ضع الملفات في `assets/covers/` ثم غيّر قيمة `cover` في `js/data.js`.
- ملفات PDF: ضع الملفات في `assets/pdfs/` ثم غيّر `pdf: null` إلى مسار الملف.
- صور الخريجين: ضعها في `assets/graduands/` ثم غيّر قيمة `image`.
- النصوص التعريفية والملخصات: عدّل الحقول في `js/data.js` و`about.html`.

كل المحتوى الحالي موسوم أو مصاغ كمحتوى تجريبي، ولا يمثل معلومات حقيقية غير مقدمة.

لا يحتاج هذا الإصدار إلى Node.js أو Express أو أي خادم خلفي. كل التفاعل يعمل مباشرة في المتصفح.
